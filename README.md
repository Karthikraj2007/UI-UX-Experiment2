# UI-UX-Experiment2

## Aim:
To design responsive mobile and web layouts in Figma by applying Gestalt principles, incorporating appropriate UI elements and design patterns, implementing interactive behaviours and usability principles, and creating a custom brand logo using Canva.

### **Algorithm:**

1\. First, define the brand identity, colour scheme, and typography for the design.
2\. Create a brand logo using Canva and export it as a transparent PNG image.
3\. Open Figma and set up separate desktop and mobile frames with appropriate layout grids.
4\. Import the created logo into Figma and add UI elements such as navigation bars, cards, buttons, and text fields.
5\. Apply Gestalt principles such as proximity, similarity, alignment, and visual hierarchy to organize the layouts.
6\. Define interaction states and incorporate usability and accessibility principles into the design.
7\. Review the completed mobile and web layouts, make necessary corrections, and export the final UI screens.
